# Until Someone Apologizes

One line, as the office printer would finally say it back to everyone staring at it: the paper jams, the cryptic error codes, the thumps when it stops working.

> Error 0xE3: sheet 41,209 is inside me. It stays there until someone apologizes.

The program writes that single line to `/output/entry.txt` — 79 characters, one line, UTF-8. It validates the 1–240 character gate before writing.
